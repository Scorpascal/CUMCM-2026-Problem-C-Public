# 官方输入的本地准备

本仓库和公开 ZIP 不分发官方题面、原始输入或空白结果模板。请从合法官方渠道取得与本项目相同版本的附件，并按下列结构放置。不要用归档的已填结果表替代空模板。

```text
code/
└── 附件/
    ├── 附件1.xlsx
    ├── 附件2.xlsx
    ├── 附件3.xlsx
    ├── 附件4.xlsx
    └── 附件5/
        ├── result1.xlsx
        ├── result2.xlsx
        ├── result3.xlsx
        ├── result4-2.xlsx
        └── result4-3.xlsx
```

Q1 使用附件1及 result1 模板；Q2 引入全年实际数据；Q3 引入滚动光伏预报；Q4 引入价格数据。完整 Q3 工作流需要附件1–3及前三个模板，Q4 需要上列全部文件。`code/reproduce.py` 在计算前检查对应输入是否齐全。

保持工作表名、列标签、时刻格式及单位与原模板一致，不覆盖原始下载文件。原始输入可包含题目编制者的作者元数据，这些不代表本项目团队身份。

`code/附件/` 已纳入 `.gitignore`，只在自己的工作副本中使用。完整性工具忽略这个本地输入目录，数值测试会对实际读取的内容执行模型契约检查。
