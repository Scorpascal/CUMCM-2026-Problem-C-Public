# 公开副本的来源与边界

发布日期：2026-10-19。原始开发仓库保持私有；本仓库从新的根提交开始，不携带旧分支、PR 引用或提交身份信息。

## 内容来源

- Python 源码以正式论文支撑材料中的 37 个 Python 文件为基线。这套提交副本已经适配无原始冻结清单、无私有 Node 预览依赖的环境。
- 五个结果工作簿、精选图表、中间结果、归档论文 PDF 与 AI 工具说明来自标准交付材料。
- Q3/Q4 Release 另外提供主工作区中对应问题的数值 CSV、JSON、NPZ 和图表；这些数字结果不重新求解或改写。
- Q3 包含 Q1–Q3；Q4 包含 Q1–Q4，包括跨问题诊断需要的前序数组。Release 将结果工作簿同时放入 results/ 和相应 code/Q*/，以满足原有输出测试的读取路径。

所有公开文件均在各自的 `PUBLIC_MANIFEST.json` 中列出大小和 SHA-256。代码对应关系见 [CODE_PROVENANCE.json](CODE_PROVENANCE.json)。原始 Q3/Q4 v2 ZIP 的散列只用于来源标识，它们仍留在私有档案，不是 Release 附件。

## 公开包装改动

相对于正式提交支撑代码，仅修改五个包装/报告文件：

| 文件 | 改动 |
|---|---|
| `code/reproduce.py` | 增加 Q3/Q4 范围选择、输入检查、明确的缺文件错误及对应审计入口 |
| `code/Q3/audit_q3.py` | 未打包的原冻结检查保留 `not_packaged`，不再误述为实际执行成功 |
| `code/Q4/audit_q4.py` | 原工程保护文件数量按实际状态描述，不硬编码旧数量 |
| `code/Q3/report_q3.py` | 生成面向公开包的复现说明，不推荐缺失的旧冻结/私有预览工具 |
| `code/Q4/report_q4.py` | 同上，移除对旧 ZIP 和未打包可选工具的依赖说明 |

核心优化、预测、结算与实验算法未因公开发布而调整。以上修改仅作用于新的公开副本，原始冻结代码、论文、结果及 ZIP 的字节保持不变。公开包不沿用原始冻结清单的名称或验证结论。

## 排除项

不公开原始 Git 历史、所有旧 ZIP、个人路径日志、机器缓存、软链接、Office 锁文件、内部生成器/备份、原环境记录、原冻结/交接散列表、未经本轮验证的旧验证状态文件，以及第三方论文全文和字体文件。官方题面、输入附件、空模板由读者自行取得。

归档论文、模型记录与数值实验中的历史叙述保留其研究语境。它们可能提及原工程中未公开的文件或过去的检查；本轮公开验证以 [VALIDATION.md](VALIDATION.md) 为准。

## 完整性与复现

外层 `.zip.sha256` 核对下载文件；包内 `PUBLIC_MANIFEST.json` 核对解压后的分发文件。散列只能证明文件对应关系，不能代替隐私检查或科学正确性判断。

完整性检查请在重算前运行。重算会改变工作副本中的 code/Q*/ 输出，原始下载包应单独保留。需要官方数据才能进行数值测试；本地输入目录和运行缓存不计入公开文件散列清单。
